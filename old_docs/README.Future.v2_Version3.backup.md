# Future Features and Expansion (v2) — NFT Trading Game

**Note:** This document describes planned features for future versions. These are _not_ currently implemented.

## Proposed Enhancements

- **Graphical User Interface:** Replace text-based UI with graphical marketplace and NFT displays (React + Tailwind CSS).
- **Dynamic Collector Focus:** NPC Collectors shift focus based on market trends.
- **Player-Triggered Events:** Players can initiate market events for strategic advantage.
- **Batch Management:** Market groups NFTs with the same description.
- **TypeScript Integration:** Full type safety across all components.

See the main README and [README.Gameplay.v2.md](README.Gameplay.v2.md) for current features.
